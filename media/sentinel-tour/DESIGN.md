# SENTINEL AI video identity

## Overview
Use the existing frontend as the visual source. This is a factual product walkthrough for first-time administrators, centered on the sample incident and the human decision. Actual screen captures remain unchanged.

## Colors
- Background #f7f9fc; surface #ffffff; primary text #10172f; secondary text #526078; border #e3eaf3.
- Primary action #1261d8. Manager #2461d7, Monitoring #087f6b, Diagnosis #7e46cf, Repair #925815, Testing #087481, Reporting #5968c6.

## Typography
Use local Segoe UI for narration cards and Bahnschrift for display, matching the frontend's Windows identity. Use Consolas only for route labels. Display 64px, supporting text 32px, captions 32px minimum on a 1920×1080 frame.

## Elevation
Use a light screenshot frame, a quiet border, and soft blue-tinted shadows. Text stays on opaque light surfaces for predictable contrast.

## Components
Each scene places a large role or page heading and concise explanation next to a real workspace capture. A persistent prototype disclosure and readable caption band establish context. Route labels correspond to existing pages.

## Do's and Don'ts
Keep approval, application and verification distinct. Show failures and limitations truthfully. Use real source screens with slight camera movement. Avoid fake metrics, invented capabilities, production claims, busy transitions, or background music competing with narration.
